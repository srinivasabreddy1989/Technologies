Python learning
---------------
Python Libraries:
    A Python library is a collection of pre-written code that you can reuse in your program.
    example: import math
    math → library/module
 Python Modules : 
 A module is simply a Python file (.py) containing reusable code.
Python Web Frameworks:
A web framework is a set of tools that helps you build web applications and APIs using Python.
Popular Python Web Frameworks:
| Framework                 | Common use                   |
| ------------------------- | ---------------------------- |
| **Django**                | Full web applications        |
| **Flask**                 | Simple web apps/APIs         |
| **FastAPI**               | Modern APIs/backend services |
| **Django REST Framework** | REST APIs with Django        |
| **Tornado**               | Async/network applications   |
Web application = the overall application users interact with.

Frontend = what users see.
Backend = Python code running behind the scenes.
Backend service = a backend component providing a specific capability.
API = a way for software to communicate with software.
REST API = an API commonly using HTTP methods like GET, POST, PUT, DELETE.
FastAPI = a Python framework for building APIs/backend services.
Async = a programming approach that can handle waiting operations without blocking other useful work.
Network application = an application communicating over a network.

How to use multiple versions of python:
1. Using python launcher : PY   py -0
2. pyenv : pyenv install 3.11.9

virtual environment:
A virtual environment creates an isolated Python project environment, mainly so the project's installed packages don't interfere with other projects.
python -m venv venv
To activate: venv\Scripts\activate
Deactivate: deactivate
